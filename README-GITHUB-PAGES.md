# Cheshta Digital Professional V2

## GitHub Pages
1. Create a GitHub repository, e.g. `cheshta-digital-tools`.
2. Upload `index.html` to the repository root.
3. Repository → Settings → Pages.
4. Source: Deploy from a branch.
5. Branch: `main`, folder: `/ (root)`, Save.
6. GitHub will show the published website URL.

## Custom domain
Settings → Pages → Custom domain. Enter your purchased domain and configure DNS using the exact records GitHub displays.

## Included
- Photo resize + target KB
- Signature resize + target KB
- PDF compression target 100/200/300 KB
- PDF merge
- JPG/PNG to PDF
- Responsive Gujarati UI
- Cheshta Digital branding and WhatsApp button

This is a static browser-side website. PDF libraries are loaded from public CDNs, so internet access is required for those functions.
